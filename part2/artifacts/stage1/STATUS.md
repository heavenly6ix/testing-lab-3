## Найденные проблемы требований

Основные: не определены календарные границы/annual anchor; snapshots и currency correction конфликтуют без политики истории; replay после коррекции может нарушить «первоначальный результат»; отсутствует таблица переходов; атомарность и конкурентная уникальность не следуют из обычной проверки mock; N04 не определяет окно/граничные попытки; daily backup сам по себе не даёт RPO15 min; локальные проверки не доказывают N05/R01–R03. Подробная классификация всех ID — docs/requirements-review.md.

Это дефекты/неоднозначности спецификации, не подтверждённые дефекты ещё не созданного backend. Выполненные статические проверки документов не называются unit/API/smoke tests.
